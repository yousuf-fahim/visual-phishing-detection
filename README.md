# Visual Phishing Detection

Visual phishing detection for a Neural Network lab: screenshot classifier vs URL features vs fusion, tested for generalization across time and language, with brand identification of the imitated site.

(This README is a kick-off stub. Phase 9 replaces it with the real one.)

## Start here

1. Read `PLAN.md` (10 minutes): research questions, time estimate, setup checklist.
2. Download the datasets into `data/raw/` (links in `PLAN.md`).
3. Open a terminal in this folder and run `claude`.
4. Either paste the prompts in `prompts/` one at a time starting with `00-setup.md`, or for an unattended run tell Claude Code: Read AUTOPILOT.md and follow it exactly.

## Folder map

- `CLAUDE.md`: project and safety rules Claude Code reads automatically.
- `PLAN.md`: plan, time estimate, risks, dataset notes.
- `AUTOPILOT.md`: instructions for an unattended run of all phases.
- `prompts/`: one prompt per phase, 00 to 09.
- `docs/learning-log.md`: filled in by Claude Code after each phase. Your viva notes.
- `data/`, `src/`, `models/`, `results/`, `web/`, `notebooks/`: empty for now.
